Settings

Open RuneLite’s configuration panel, find Goal Tracker, and adjust the settings below. Changes apply to the plugin as soon as they are saved.

Horizontal Scroll Speed

Controls how far content moves during each horizontal scroll step. This is useful for wide task hierarchies and other content that needs sideways scrolling.

  • Supported range: 1–100.
  • Default: 12.

Vertical Scroll Speed

Controls how far content moves during each vertical scroll step. The setting applies throughout scrollable plugin content, including long task lists, changelogs, and resized Add Child dialogs.

  • Supported range: 1–100.
  • Default: 12.

Completion Message Color

Choose the color used for the chat message shown when a goal is completed.
