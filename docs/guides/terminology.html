Terminology

This page explains the names used for the plugin’s screens and the relationships between tasks.

Plugin Screens

Home Panel
The main Goal Tracker view that lists your goals. Use it to create or open goals, add presets, and organize the goal list.
Goal Panel
The view for one goal. It shows that goal’s tasks and controls for adding, editing, and organizing them. Use Back to return to the Home Panel.

Goals and Tasks

Goal
A named collection of related tasks. A goal appears as one entry on the Home Panel.
Task
An individual objective within a goal, such as reaching a skill level, completing a quest, collecting items, or checking off a custom objective.

Task Relationships

Parent
A task that has one or more tasks nested beneath it.
Child
A task nested beneath a parent task. Its indentation shows the relationship.
Sibling
Two or more tasks that share the same parent. Root tasks can also be siblings when they appear at the same level in the goal.
Ancestor and descendant
An ancestor is a parent anywhere above a task in a nested branch. A descendant is a child or deeper nested task below it. For example, a task can be a grandchild of its grandparent task.
Root task
A task in a goal that has no parent.
