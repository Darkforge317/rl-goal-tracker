Importing and Exporting Goals

Use JSON files to make a backup of your goals or copy them between RuneLite profiles.

Export Goals to a JSON File

  1. Return to the Goal Tracker home panel.
  2. Choose Export.
  3. Select a location and file name for the JSON file, then confirm.

Keep the exported file somewhere safe. It contains your goals and task data, including parent/child relationships.

Import Goals from a JSON File

  1. From the home panel, choose Import.
  2. Select the JSON file.
  3. Choose whether to overwrite your existing goals or merge the imported goals with them.

Inside a goal, the Import button also lets you paste JSON directly instead of selecting a file.

Overwrite or Merge

  • Overwrite replaces the current goal list with the goals from the file.
  • Merge keeps your current goals and appends the imported goals.
  • Cancel closes the prompt without importing.

Review the selected file and import mode before confirming. If you want a safety copy, export your current goals first.
