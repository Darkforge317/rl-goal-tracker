Adding Goals

Goals group related tasks so you can track a project, unlock, or checklist in one place.

Add Goal Button

From the Goal Tracker home panel, select + Add goal. The plugin opens a new, empty goal so you can add tasks right away. Use Back to return to the home list.

An empty new goal is discarded if you leave without adding any tasks. Add at least one task to keep it in your list.

Goal Name

In the goal view, use the Edit control beside the goal name. Enter a descriptive name, then choose Save. Choose Cancel to discard the unsaved name change. You can also right-click a goal on the home panel and choose Rename.

After naming the goal, add tasks using the form at the bottom of the page. See Adding Tasks.
