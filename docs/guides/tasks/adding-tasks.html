Adding Tasks

Open a goal to add tasks to it. New tasks are checked against supported RuneLite data so existing progress can be reflected right away.

Ways to Add Tasks

  • Use the Quick add field at the bottom of a goal to create a custom task.
  • Expand More options to add skill, combat-level, quest, Quest point, or item tasks.
  • Choose the green + beside a task to create a child task directly under it.
  • Use Add Quest pre-reqs at the top of the goal to add known requirements for quest tasks.

Custom / Quick Add

Enter a short description in Quick add and press Enter or choose Add. Custom tasks are manual checklist items; they do not read progress from the game.

Skill Tasks

Select a skill, then enter a target using either the Level or XP field. Updating one field updates the other to its corresponding target.

Skill Level

Enter a level from 1 to 127, including up to two decimal places. Whole levels through 99 are level tasks. Fractional levels and virtual levels are stored as the corresponding XP target so progress can be checked precisely.

Skill XP

Enter an XP target from 0 to 200 million. You can use k or m suffixes with whole numbers, such as 125k or 2m. Decimal suffixes such as 1.2m are not accepted. If you enter a level first, the XP value is calculated for you.

Combat Level

Enter a combat-level target from 3 to 126. The spinner changes in 0.25 steps and accepts up to two decimal places.

Quest

Choose a quest from the searchable list and select Add. To add its known requirements, use Add Quest pre-reqs after creating it, or add prerequisite tasks from its right-click menu. See Organizing Tasks for how task relationships are displayed.

Quest Points

Enter a whole-number target from 0 to 343 and choose Add.

Items

Search

Choose Search... to open RuneLite’s item search. Select an item to return to the task form. When creating a child task, the Add Child window temporarily hides during item search so the RuneLite chatbox can receive input.

Quantity

Enter the quantity to track. The quantity must be a positive whole number; k and m suffixes are accepted. Then choose Add.

Automatic Completion Checks

When a task is added, the plugin checks task types supported by the current RuneLite state. For example, an existing skill level, completed quest, Quest point total, or cached item count can make a new task show progress or completion immediately. If the relevant data is not currently available, it will update when RuneLite reports it.
