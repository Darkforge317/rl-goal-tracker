Editing Tasks

You can edit the target of skill level, skill XP, combat-level, Quest point, and item tasks. Quest and custom tasks do not have an editable target in the current interface.

Edit a Task

  1. Right-click the task row.
  2. Choose Edit.
  3. Change the target value in the dialog.
  4. Choose Save to apply the change or Cancel to close without saving.

Skill tasks let you switch between a level target and a direct XP target. Item tasks let you change the requested quantity. Combat Level and Quest point tasks let you change their numeric target.

What Stays the Same

Editing a target keeps the task in its existing list position and preserves its parent/child relationships. The plugin rechecks the edited target against available player data after you save.
