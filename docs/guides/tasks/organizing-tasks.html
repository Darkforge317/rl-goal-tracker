Organizing Tasks

Tasks can be reordered and grouped into explicit parent/child relationships. The hierarchy is shown through indentation and can be collapsed to hide a branch.

Drag and Drop

Drag a task row to a valid insertion slot. Dragging a parent moves its entire subtree, including its descendants. A child stays within the sibling positions belonging to its current parent; it cannot be dragged out of that parent. Use Set parent when you want to change its relationship.

An unparented task cannot be dropped into the middle of another task’s child branch to become a child. Assign the parent explicitly with Set parent.

Right-click a task and use the Move menu to move it up or down, or to the top or bottom where available.

Parent, Child, and Sibling Tasks

A parent task groups one or more child tasks beneath it. Tasks with the same parent are siblings. A child may also be a parent, allowing nested requirement or project trees. Indentation reflects the relationship stored between tasks.

Assign a Parent to a Task

  1. Right-click the task that should become a child.
  2. Choose Set parent....
  3. Hover over a task. A green row and plus cursor indicate a valid parent; a red row and X cursor indicate an invalid target.
  4. Click a valid task to assign it as the parent.

Right-click or press Escape to cancel parent selection.

Invalid Parent Relationships

A task cannot be its own parent, its current parent, or one of its descendants. The selection is also rejected if it would exceed the supported hierarchy depth. Hover over an invalid row to see the reason.

Remove Parent

Right-click a child and choose Remove parent. The task becomes a sibling of its former parent, or a root task if the former parent had no parent. It is placed after the former parent’s full subtree, keeping the remaining children grouped together. For example, detaching C2 from B2 under A places C2 after B2’s children and before B3.

Collapse and Expand

Use the arrow beside a task with children to collapse or expand its branch. Collapsing hides descendants without removing them. The parent and its descendants still move together when dragged.
