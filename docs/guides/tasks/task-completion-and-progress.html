Task Completion and Progress

Tracked task types update from RuneLite data when that data is available. Custom tasks are manual. Task completion can also be changed from the task’s right-click menu.

Automatic Progress Updates

  • Skill level and XP: update when the matching skill progress changes and when player data is refreshed.
  • Combat Level: updates from the current real combat skills and retains the last observed value across logouts and world hops.
  • Quests: use RuneLite’s quest state and can show not started, in progress, or completed.
  • Quest Points: update from the player’s current Quest point total.
  • Items: use cached quantities from tracked containers. Container changes refresh their counts when RuneLite exposes them.
  • Custom: has no automatic progress source.

Newly added tasks are checked against available progress. A task can therefore appear in progress or complete as soon as it is added.

Manually Change Completion

Right-click a task and choose Mark as Completed or Mark as Incomplete. For a task with descendants, the manual change applies to that task and its subtree.

Manual completion is useful for custom tasks and for overriding a tracked task temporarily. An incomplete tracked task may become complete again when RuneLite data next shows that its target is met. Completed item tasks stop updating automatically until you mark them incomplete.
