Undoing and Redoing Task Changes

The goal view’s Undo and Redo buttons track supported task-list actions while that goal is open. The buttons are disabled when there is no action to undo or redo.

Supported Actions

  • Remove a task and its descendants.
  • Change a task’s parent or remove its parent.
  • Reorder tasks using drag and drop or the Move context-menu options.
  • Manually mark a task and its descendants complete or incomplete.
  • Add a child task using the row’s + button.

Use Undo or Redo

Choose Undo to reverse the latest supported action. Choose Redo to apply it again. Making a new supported change after undo clears the redo sequence.

The current history does not include ordinary task additions from the bottom form, task target edits, or adding quest prerequisites. Those changes are saved normally but cannot be reversed with these buttons.
