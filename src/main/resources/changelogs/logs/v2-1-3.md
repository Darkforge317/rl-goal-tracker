Hi everyone, we've got another great update for you today!

Track combat level directly alongside your other goals, with progress saved between sessions.

---

## New Features
- **Combat level goals**: Create and edit combat-level targets from 3 to 126 with up to two decimal places. Progress is shown as the target (for example, `85.25 Combat`) and the current combat level is cached between logouts and world hops.

## Quality of Life
- **Scroll speed settings**: Configure horizontal and vertical scrolling throughout the plugin independently, including task lists, changelogs, and resizable dialogs.

## Bug Fixes
- **Charged item goals**: Count charged variants together and display their shared base name in item task titles (for example, `94/100 x Super Energy` instead of `94/100 x Super Energy(4)`).
- **Blood Moon Rises prerequisites**: Add its required skill levels and quest prerequisite chain to generated prerequisites.
- **Dream Mentor prerequisite**: The required level is now correctly tracked as combat level 85 instead of Defence 85.
- **Add child item selection**: Keep the item search usable while adding a child task, so the RuneLite chatbox search can receive keyboard input.
