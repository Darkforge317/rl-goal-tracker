Track combat level directly alongside your other goals, with progress saved between sessions.

## New Features
- **Combat level tasks**: Create and edit combat-level targets from 3 to 126 with up to two decimal places. Progress is shown as the target (for example, `85.25 Combat`) and the current combat level is cached between logouts and world hops.
- **Quest point tasks**: Create and edit Quest point targets, with live progress updated from the player's Quest point total and cached between sessions.

## Quality of Life
- **Scroll speed settings**: Configure horizontal and vertical scrolling throughout the plugin independently, including task lists, changelogs, and resizable dialogs.

## Bug Fixes
- **Goal loading safety**: Preserve the current goal list if saved goal data is missing or cannot be parsed, instead of clearing the list before a failed load.
- **Charged item goals**: Count charged variants together and display their shared base name in item task titles (for example, `94/100 x Super Energy` instead of `94/100 x Super Energy(4)`).
- **Item selection during child task creation**: Keep the item search usable while adding a child task, so the RuneLite chatbox search can receive keyboard input.
