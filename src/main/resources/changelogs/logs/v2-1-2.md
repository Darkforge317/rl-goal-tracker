Hi everyone, we've got another great update for you today!

We've introduced some bug fixes that have been long past due, a bunch of Quality of Life updates, and made organizing your tasks much easier with collapsibles and parenting! 
## New Features

- **Parent and child tasks**: Create children with the + button, assign or remove parents from the task menu, and drag parents with their descendants. Indentation now reflects the saved parent-child relationship.
- **Collapsible tasks**: Collapse a parent to hide its descendants, using the arrow beside its icon or the task menu. Collapsed state is saved between sessions.
- **Changelogs**: This panel! Keeping you up to date on what's changed in each update.

## Quality of Life

- **Edit existing goals**: Change skill level, skill XP, and item quantity targets without deleting and recreating goals. Edits preserve the task's list position and hierarchy.
- **Skill goal form**: Create level or XP goals from one icon-based skill selector, with synchronized level and XP fields. XP targets also accept abbreviated values.
- **Virtual Levels**: You can now set virtual level tasks up to level 127 (200m xp) 
- **Fractional Levels**: You can set a fractional level target. (e.g. 12.5 means the halfway point from level 12 to level 13)
- **Item goal form**: Preview and change the selected item before adding it, enter quantities with `k` and `m` suffixes, and use quantity controls for adjustments.
- **Undo and redo**: Parent changes, task moves, and task removals can now be undone and redone.

## Bug Fixes

- **Accurate item counts**: Keep item-task progress correct across inventory, bank, and Group Ironman shared-storage transfers; preserve cached bank counts during unrelated inventory changes; exclude placeholders and prevent duplicate counts.
- **Item task icons**: Load icons asynchronously and refresh task rows when the images are ready, including for imported goals.

## Developer Improvements

- **RuneLite API updates**: Replace deprecated inventory and item ID enums with supported container and game value IDs.
- **More reliable tests**: Add coverage for task hierarchy, drag constraints, interaction states, undo and redo, and serialization. Fix the failing tests tracked by issue #29.
